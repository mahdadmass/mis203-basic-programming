# Lab Quiz Week 02 - Purchase Quote Program

This repository contains the solution for the Week 02 laboratory assignment. The Python program calculates a purchase quote for two items including tax and delivery fees.

## Test Executed
- **Item 1:** Quantity = 2, Price = 50.00
- **Item 2:** Quantity = 1, Price = 80.00
- **Delivery Fee:** 20.00
- **Tax Rate:** 10%
- **Result:**
  - Subtotal: 180.00 TRY
  - Tax (10%): 18.00 TRY
  - Delivery Fee: 20.00 TRY
  - **Final Total: 218.00 TRY**

## Changes Made After Testing
- Added explicit string formatting (`:.2f`) for all float outputs to ensure exact two decimal places format as required by the specifications.
- Refactored prompt messages to make user input prompts clearer.
