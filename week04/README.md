# Two-Way Number Game 

A fun and interactive Python command-line game built for the **GitHub 4 Surprise Assignment**.

##  Features
This project features two different game modes:
1. **User Guesses Mode**: The computer generates a random number between 1 and 100, and the user tries to guess it while getting hints (`HIGHER` / `LOWER`) and a timer.
2. **Python Mind Reader Mode**: The user secretes a number, and Python guesses it efficiently using the **Binary Search Algorithm**.

##  Python Libraries Used
This project uses two standard Python libraries:
* `random`: To generate pseudo-random numbers.
* `time`: To calculate the time taken to guess the secret number.
